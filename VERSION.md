# Director v0.6.0

## What changed
- Stream Scheduler now automatically creates recurring Stream blocks in Calendar for the configured weekdays.
- Separate editable Stream start/end time from the 18:00 prep reminder.
- Stream Prep popup can play a system sound.
- Tasks can be expanded with a description and an editable checklist/subtasks.
- Calendar now has a real month grid, clickable days and direct date picker.
- SQLite schema v4 stores task checklists safely through updates.
